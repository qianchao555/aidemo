# File System Skill

## 领域知识

### 沙箱安全模型

所有文件操作限制在指定的工作区目录（workspace）内：
- 路径穿越攻击（如 `../../etc/passwd`）会被自动拦截
- 工作区外的文件不可被访问、修改或删除
- 工作区目录在首次使用时自动创建

### 文件组织规范

- 使用子目录对文件进行分类管理，如 `reports/2026/`、`articles/tech/`
- 文件名建议使用有意义的命名，避免 `1.txt`、`untitled.md`
- 路径分隔符统一使用 `/`

### 操作原则

- **幂等写入**：写入同名文件会覆盖旧内容，不会产生重复文件
- **自动父目录**：写入文件时如果父目录不存在，会自动创建
- **追加需文件已存在**：追加操作要求文件已存在，避免意外创建
- **删除不可恢复**：文件删除操作不可逆，操作前确认

### 持久化策略建议

- 关键产出（报告、文章）定期保存，避免丢失
- 使用有规律的目录结构便于后续检索
- 文件名可包含日期、版本号等标识信息

## 工作流程

1. **确定目标**：明确要读、写、删还是列目录
2. **定位路径**：确定文件或目录在工作区中的相对路径
3. **执行操作**：读写文件、创建目录或追加内容
4. **验证结果**：操作后检查返回的成功状态和文件大小

## 注意事项

- 工作区根目录由应用运行时确定，不同项目的工作区位置可能不同
- 大文件写入可能耗时，Agent 应告知用户预期等待时间
- 同时操作大量文件时注意 IO 性能
