# 内容审查示例 2：综合质量评估

## 场景
编辑团队需要评估一篇即将发布的行业分析文章的质量，决定是否需要修改后再发布。

## 对话过程

**用户**：帮我全面评估这篇文章的质量，看看是否达到发布标准。目标读者是行业从业者。

### 第一阶段：可读性检查

**Agent 可读性评估**：

```markdown
综合评分：72 分（良好）

各维度得分：
- 句子复杂度：65 分 — 第 3 段句子偏长（平均 45 字/句），建议拆分
- 词汇适当性：78 分 — 第 5 段专业术语密度过高，建议首次出现时添加简要解释
- 段落结构：75 分 — 结构合理，信息层次清晰
- 逻辑连贯性：70 分 — 段落间缺少过渡句，建议在关键节点增加承上启下

优化建议：
1. 拆分第 3 段长句，控制在 25 字/句以内
2. 为首次出现的专业术语添加一句话解释
3. 在 4→5 段、6→7 段之间增加过渡句
```

### 第二阶段：综合质量评估

**Agent 综合评估**：

```markdown
综合得分：76 分
结论：有条件通过 (conditional_pass)

维度评分：
- 安全性  92 分 (25%) — 内容安全，无明显违规风险
- 可读性  72 分 (25%) — 对目标读者友好，部分段落可优化
- 原创性  68 分 (20%) — 有一定新颖性，但部分分析较为常规
- 结构性  80 分 (15%) — 结构完整，逻辑清晰
- 信息密度 65 分 (15%) — 部分段落信息密度偏低，存在冗余

强项：
- 数据引用丰富，来源标注规范
- 分析框架完整，覆盖多个维度
- 语言专业但不晦涩

弱项（需修改）：
- 开头铺垫过长，核心观点在第 5 段才点明 → 精简开头，提前核心观点
- 第三部分原创观点不足 → 补充差异化分析角度
- 结尾缺乏有力的行动建议 → 增加实操建议章节
```

### 第三阶段：优化闭环

编辑团队根据评估结果：
1. 细化段落结构，将核心观点前移
2. 补充差异化分析维度
3. 添加"行动建议"章节

优化后重新评估：综合得分 88 分，达到发布标准。

## 关键启示
- 多维度打分比单一维度更全面客观
- conditional_pass 是最常见的中间状态，指出的问题即优化路线
- 评估结果中的弱项直接对应优化方向
- 推荐"审查 → 优化 → 再审查"闭环，而非一次审查就做最终决定
