# Content Moderation Skill

## 领域知识

### 安全审查标准

内容安全审查分为三个严格程度：

| 严格度 | 检测范围 | 适用场景 |
|--------|---------|---------|
| **low** | 明显违规（色情、暴力、违法） | 宽松社区、内部论坛 |
| **medium** | 标准审查（增加人身攻击、歧视、谣言） | 一般公开平台 |
| **high** | 严格审查（增加隐晦表达、擦边内容） | 严肃平台、教育场景、儿童内容 |

审查结论分三级：
- **pass**：通过，内容合规
- **review**：需人工复核，存在需判断的边界情况
- **fail**：不通过，存在明确违规

风险等级：low → medium → high → critical

### 敏感词处理模式

- **mask 模式**：将敏感词替换为 `***` 脱敏处理，适合公开发布场景
- **suggest 模式**：提供同义替换建议，在保持语义完整的前提下合规化

### 可读性评估

评估维度：
1. **句子长度与复杂度**：过长的句子降低理解效率
2. **词汇难度与准确性**：生僻词过多增加阅读门槛
3. **段落结构与逻辑连贯性**：段落过长或跳跃影响理解
4. **整体通顺度与节奏感**：文字是否自然流畅

评分：0-100 分，分数越高越易读。评估时应考虑**目标读者群体**（如小学生、专业人士、普通大众）调整标准。

### 综合质量评估

从五个维度对内容进行全方位评价：

| 维度 | 评估内容 | 权重建议 |
|------|---------|---------|
| 安全性 (Safety) | 违规风险、敏感内容 | 30% |
| 可读性 (Readability) | 流畅度、逻辑清晰度 | 25% |
| 原创性 (Originality) | 内容新颖度、独特视角 | 20% |
| 结构性 (Structure) | 篇章布局、段落组织 | 15% |
| 信息密度 (Density) | 有效信息占比 | 10% |

### 审查场景推荐

| 场景 | 推荐严格度 | 推荐动作 |
|------|:------:|------|
| 社交媒体评论 | medium | 安全审查 + 敏感词检测 |
| 正式文章发布 | high | 安全审查 + 综合评估 |
| 儿童教育内容 | high | 安全审查(high) + 可读性检查 |
| 内部文档 | low | 仅基础安全检查 |

## 工作流程

1. **初步筛选**：进行安全审查，快速筛查违规内容
2. **敏感词处理**：如有敏感内容，检测并替换
3. **可读性优化**：评估可读性，根据建议调整
4. **综合评估**：最终质量把关，多维度评分

## 注意事项

- 审查结果仅供参考，关键决策建议人工复核
- high 严格度可能产生更多误报，根据场景权衡
- 敏感词标准会不断变化，需持续更新
- 综合评估耗时较长，建议仅在重要内容发布前使用
