# Content Creator Skill

## 领域知识

### 写作方法论

**金字塔原理**：结论先行，以上统下，归类分组，逻辑递进。先给出核心观点，再用论据支撑。

**倒金字塔结构**（新闻类）：最重要的信息放在最前面（5W1H），次要信息按重要性递减排列。

**AIDA 模型**（营销类）：Attention（吸引注意）→ Interest（激发兴趣）→ Desire（唤起欲望）→ Action（引导行动）。

### 文体与结构

| 文体 | 适用场景 | 推荐结构 |
|------|---------|---------|
| 博客/技术文章 | 知识分享、技术教程 | 背景 → 问题 → 方案 → 实践 → 总结 |
| 新闻报道 | 事件报道、快讯 | 标题 → 导语 → 正文 → 背景 → 结语 |
| 散文/随笔 | 文学创作、个人表达 | 引入 → 展开 → 高潮 → 收尾 |
| 论文/报告 | 学术研究、商业分析 | 摘要 → 引言 → 方法 → 结果 → 讨论 → 结论 |
| 营销文案 | 产品推广、品牌宣传 | 痛点 → 解决方案 → 产品介绍 → 信任背书 → 行动号召 |

### 标题技巧

- **数字法**："5 个提升写作效率的技巧"
- **提问法**："为什么你的文章没人看？"
- **对比法**："传统写作 vs AI 写作：优劣对比"
- **紧迫法**："2026 年必须掌握的 3 种写作文体"

标题风格选择：
- **catchy**：吸引眼球，适合社交媒体、公众号
- **professional**：专业严谨，适合行业报告、技术文档
- **elegant**：优雅文艺，适合散文、书评、文化类内容

### 润色原则

1. **不改原意**：润色应提升表达质量，不改变作者原意
2. **删繁就简**：删除冗余词汇，一句话能说清的不说两句
3. **主动优先**：多用主动语态，少用被动语态
4. **长短结合**：长短句交替使用，保持节奏感

润色维度：
- **clarity**：提升逻辑严密性和表达准确性
- **fluency**：提升语言自然度和通顺度
- **engagement**：增强内容吸引力和感染力

### 摘要技巧

- 抓住核心观点，忽略细节论据
- 保持原文逻辑顺序
- 控制长度：short(~100字) / medium(~200字) / long(~300字)
- 用自己的话重述，不直接复制原文

## 工作流程

典型的创作流程如下：

1. **明确需求**：了解创作目标、目标读者、发布平台
2. **生成初稿**：基于主题和文体生成文章初稿
3. **优化标题**：为文章配上吸引人的标题
4. **内容润色**：打磨关键段落，提升表达质量
5. **生成摘要**（可选）：提炼核心要点作为导语
6. **保存交付**：将完成的作品持久化保存

## 注意事项

- 首次创作前，引导用户明确内容类型和目标读者
- 不满意时优先微调润色，而非从头重写
- 保持内容的原创性，避免模板化
- 敏感话题或专业领域内容，应进行审查把关
