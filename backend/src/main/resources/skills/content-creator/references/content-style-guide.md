# 内容创作风格指南

## 写作原则

### 1. 结构清晰
- 采用"总-分-总"结构：开篇点题 → 分点展开 → 总结升华
- 每个段落聚焦一个核心观点，段落间逻辑连贯
- 使用小标题和编号增强可读性

### 2. 语言简洁
- 一句话只说一件事，避免过长复杂句
- 删减冗余修饰词，用精准动词代替形容词堆砌
- 技术内容用通俗类比辅助理解

### 3. 内容实用
- 每个观点应有具体案例或数据支撑
- 提供可操作的步骤、清单或模板
- 避免空洞说教，聚焦"怎么做"

### 4. 读者导向
- 明确目标读者画像（技术水平、关注点、阅读场景）
- 调整语言难度：技术人员可多用术语，大众读者需通俗化
- 预判读者疑问并在文中主动解答

## 常用结构模板

### 博客文章
```
引言（抛出问题/现象）
  ↓
背景分析（为什么重要）
  ↓
核心内容（3-5 个要点，每个配案例）
  ↓
实践建议（怎么做）
  ↓
总结展望
```

### 新闻报道
```
导语（5W1H）
  ↓
事件详情（时间线）
  ↓
多方观点（引用）
  ↓
背景补充
  ↓
后续影响
```

### 营销文案
```
痛点共鸣
  ↓
解决方案引入
  ↓
产品/服务优势（3 点）
  ↓
信任背书（案例/数据/评价）
  ↓
行动号召（CTA）
```

## 标题公式

| 类型 | 公式 | 示例 |
|------|------|------|
| 数字型 | 数字 + 关键词 + 价值承诺 | "5 个提升写作效率的 AI 工具" |
| 问题型 | 设问 + 痛点 | "为什么你的文章总是没人看？" |
| 对比型 | A vs B + 结论暗示 | "AI 写作 vs 人工写作：谁更胜一筹？" |
| How-to 型 | 如何 + 动词 + 目标 | "如何在 30 分钟内写出一篇爆款文章" |
| 揭秘型 | 修饰词 + 真相/秘密 | "顶级写作者不会告诉你的 3 个秘诀" |

## 行文技巧

### 开头技巧
- **悬念式**："你有没有想过，为什么有些文章读完就忘，有些却能记住好几年？"
- **数据式**："据统计，80% 的读者只会阅读文章的前 300 字。"
- **故事式**："去年三月，我遇到了一位彻底改变我写作方式的人..."

### 过渡技巧
- 使用转折词：然而、与此相反、更重要的是
- 使用递进词：不仅如此、更进一步、深层来看
- 使用总结词：总而言之、归根结底、核心在于

### 结尾技巧
- **总结式**：提炼全文核心观点
- **行动式**：给出明确的下一步建议
- **展望式**：预测趋势或提出开放性问题
- **金句式**：用一句精炼的话收尾

## 不同平台的风格适配

| 平台 | 标题风格 | 篇幅 | 语言调性 | 配图建议 |
|------|---------|------|---------|---------|
| 微信公众号 | catchy + 数字 | 1500-3000 字 | 亲切有料 | 每 300 字配图 |
| 知乎 | professional + 问题 | 2000-5000 字 | 严谨深度 | 数据图表 |
| 小红书 | catchy + 情感 | 500-1000 字 | 种草口语 | 多图少字 |
| 技术博客 | professional | 2000-4000 字 | 专业准确 | 代码+流程图 |
| 公司内刊 | elegant + professional | 1000-2000 字 | 正式得体 | 活动照片 |
