# PwC 风格 UI 重设计 — 设计文档

日期：2026-06-03

## 概述

对现有制度知识库问答系统进行全面的 UI 视觉重设计，采用 PwC 风格（Professional Warm）的专业企业级设计语言。所有现有功能保持不变，仅涉及前端视觉层面的改造。

---

## 一、设计系统

### 1.1 色彩体系

| Token | 色值 | 用途 |
|-------|-------|------|
| Primary | `#E87040` | 按钮、激活态、强调色、高亮条 |
| Primary Hover | `#D96030` | 按钮悬停态 |
| Sidebar BG | `#2D2D2D` | 图标侧边栏、登录页暗色面板 |
| Surface Warm | `#FAF9F7` | 会话列表面板、输入框、统计卡片 |
| Page BG | `#F5F3F0` | 主内容区背景 |
| White | `#FFFFFF` | 聊天区、内容卡片 |
| Text Primary | `#1A1A1A` | 标题、正文 |
| Text Secondary | `#666666` | 次要文本 |
| Text Muted | `#999999` / `#BBBBBB` | 时间戳、占位文本 |
| Border | `#E8E4E0` / `#F0ECE6` | 卡片边框、分割线 |

### 1.2 圆角与阴影

- 大圆角：12px（卡片、弹窗、聊天气泡）
- 中圆角：8px（按钮、输入框、侧边栏图标）
- 小圆角：4px（标签、小型元素）
- 卡片阴影：`0 2px 12px rgba(0,0,0,0.06)`
- 弹窗阴影：`0 4px 24px rgba(0,0,0,0.10)`

### 1.3 字体

使用系统默认字体栈，保证中英文渲染质量。标题加粗 600–700，正文常规 400，字号层级清晰。

## 三、登录页

### 3.1 布局

全屏暗色沉浸式设计，无侧边栏和顶栏。

- 背景：深色渐变 `#2D2D2D` → `#1A1A1A`
- 装饰：大尺寸低透明度 coral 圆形光晕（`rgba(232,112,64,0.05–0.08)`）
- 居中毛玻璃卡片：
  - 背景 `rgba(255,255,255,0.05)` + `backdrop-filter: blur(10px)`
  - 边框 `1px solid rgba(255,255,255,0.08)`
  - 圆角 14px，padding 36px 30px，宽度 360px

### 3.2 卡片内容

- 顶部：coral 色方形 Logo 图标 (44px)
- 应用名称 "制度问答与流程指引助手"（白色 16px 加粗）
- 副标题 "登录您的账号"（灰色 10px）
- 输入框：暗色背景 `rgba(255,255,255,0.08)`，白色文字，圆角 8px
- 登录按钮：coral 背景，白色文字，全宽，圆角 8px，高 40px
- 底部提示文字（灰色 10px）

## 四、智能问答页（Chat）

### 4.1 三栏布局

```
┌───┬──────────────┬─────────────────────────────────────┐
│ 图 │ 会话列表面板  │  聊天区域                            │
│ 标 │ (240px)      │                                     │
│ 侧 │              │  · 消息列表                          │
│ 边 │              │  · 输入区域                          │
│ 栏 │              │                                     │
└───┴──────────────┴─────────────────────────────────────┘
```

### 4.2 会话列表面板 (240px, `#FAF9F7`)

- 顶部：coral "新建对话" 按钮，全宽，高 36px
- 会话列表项：
  - 标题（首条用户消息截取，最多 30 字符）
  - 副信息（消息数 + 相对时间）
  - 激活项：coral 左边框 3px + 浅 coral 背景 `rgba(232,112,64,0.08)`
  - 悬停项：浅灰背景
  - 右侧删除按钮（hover 显示）

### 4.3 聊天区域

- 白色背景，flex 列布局
- **欢迎页**（无会话时）：
  - 居中大标题 "AI 智能问答"
  - 副标题说明文字
  - 示例问题卡片网格（hover 变 coral 色调）
- **消息气泡**：
  - 用户消息：coral 背景 + 白色文字，右对齐，圆角 `12px 12px 4px 12px`
  - 助手消息：`#F5F3F0` 背景 + 深色文字，左对齐，圆角 `12px 12px 12px 4px`
  - Markdown 渲染支持（代码块、列表等）
- **引用出处**：助手气泡下方 "引用出处 (N)" 按钮，点击弹出 Popover：
  - 检索方式信息（向量/关键词命中数、RRF 融合后数量、识别意图）
  - 引用来源列表（序号 + 文档名 + 章节路径）
- **输入区域**：
  - 多行文本输入框（`#FAF9F7` 背景，圆角 8px）
  - coral 发送按钮，loading 状态显示动画
- **流式渲染**：token 逐段追加，thinking 状态显示检索动画，done 后提取 sources

### 4.4 欢迎页示例问题

- 年假怎么申请？
- 病假需要提供什么证明材料？
- 加班费怎么计算？
- 离职流程需要多长时间？

## 五、知识库管理页

### 5.1 布局

单页堆叠卡片式，页面标题 + 副标题 + 统计卡片 + 功能卡片区。

### 5.2 统计卡片行

3 个等宽卡片水平排列：
- 文档总数
- 向量分块总数
- 分类统计（按分类展示 tag）

卡片样式：`#FAF9F7` 背景，圆角 8px，1px `#F0ECE6` 边框。

### 5.3 文件上传卡片

- 文档类型选择器（下拉）+ 解析器选择器（下拉）
- 拖拽上传区：虚线边框 `2px dashed #E0DCD5`，居中提示文字，支持点击选择
- 描述字段（可选文本输入）
- coral "上传并摄入" 按钮

### 5.4 文档管理卡片

- 工具栏：分类筛选下拉 + 状态筛选下拉 + 刷新按钮
- 表格：
  - 列：ID、文档名称、类型、分类(tag)、版本、分块数、状态(tag)、摄入时间、操作
  - 斑马纹 + 边框
  - 操作按钮：详情(弹窗) / 重新摄入(隐藏 file input) / 删除(Popconfirm)
- 空状态：`<el-empty>` 组件

### 5.5 知识搜索卡片

- 搜索输入框 + TopK 数字输入 + 搜索按钮
- 结果区：命中数量 + 搜索结果卡片（等宽字体 pre-wrap）

## 七、实施要点

### 7.1 改造策略

- **增量替换**：逐步替换 App.vue 和各页面组件的样式，不改变现有组件逻辑和 API 调用
- **全局 CSS 变量**：在 App.vue 或全局样式文件中定义 CSS 自定义属性（`--primary`, `--sidebar-bg` 等），统一设计 token
- **Element Plus 主题覆盖**：通过 CSS 变量和 scoped 样式覆盖 Element Plus 默认样式

### 7.2 文件变更清单

| 操作 | 文件 | 说明 |
|------|------|------|
| 改造 | `frontend/src/App.vue` | 图标侧边栏 + 顶栏重构，全局 CSS 变量 |
| 改造 | `frontend/src/views/auth/Login.vue` | 暗色沉浸式登录页 |
| 改造 | `frontend/src/views/agent/ChatView.vue` | 三栏布局 + 聊天气泡新样式 + 欢迎页 |
| 改造 | `frontend/src/views/knowledge/KnowledgeBase.vue` | 堆叠卡片式布局 |
| 改造 | `frontend/src/views/faq/FaqList.vue` | 统一配色/圆角 |
| 改造 | `frontend/src/views/faq/HighFreqFaq.vue` | 统一配色/圆角 |

### 7.3 不变部分

- 后端代码、API 接口、数据库结构无任何变更
- Store、Router、API 模块、TypeScript 类型定义不变
- 所有业务逻辑、会话管理、流式问答逻辑不变

## 八、自审清单

1. **占位符扫描**：无 TBD/TODO/placeholder
2. **一致性**：所有页面使用统一的设计 token（颜色、圆角、阴影），无冲突
3. **范围控制**：纯视觉改造，不涉及功能变更，不改变任何业务逻辑
4. **现有功能保持**：所有三个改造方向（增量更新、会话管理、流式问答）的交互不变
